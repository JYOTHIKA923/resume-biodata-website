## Cloud hosting
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/root`.
6. Save. GitHub provides the public website URL.

### Netlify
1. Create an account at Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the complete project folder into the deployment area.
4. Netlify generates a public URL.

### Important
The contact form is a front-end demo. It validates input but does not send email without a backend/form service.
